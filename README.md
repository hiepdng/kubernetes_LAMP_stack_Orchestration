## Containerize and orchestrate a LAMP stack with Kubernetes

To focus on Kubernetes containerization and orchestration, I use pre-configured LAMP stack images from my other project [docker_build_DHI_LAMP_Project](https://github.com/hiepdng/docker_build_DHI_LAMP_Project). All you need to do is to clone the repogitory, build the LAMP stack images, then use Kubernetes to containerize and orchestrate the LAMP stack.
