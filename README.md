## Containerize and orchestrate a LAMP stack with Kubernetes

To focus on Kubernetes containerization and orchestration, I include a directory docker_build, which is a pre-configured LAMP stack IaC from my other project [docker_build_DHI_LAMP_Project](https://github.com/hiepdng/docker_build_DHI_LAMP_Project). All you need to do is to build the LAMP stack images, then use Kubernetes to containerize and orchestrate the LAMP stack.
